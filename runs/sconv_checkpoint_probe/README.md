# Короткий сквозной прогон до контрольной точки S_conv (5000 шагов)

Прогон подтверждает работу валидационного расписания `ValidationSchedule` и расчёта `S_conv`
на реальном тракте обучения DQN (`experiments/pilot.py`, `experiments/runner.py`,
`experiments/metrics.py`) с оценкой модели на точной отметке шага (`exact_step=True`,
вызов через пошаговый обратный вызов `run_episode(..., on_step=...)` без влияния на
состояние среды обучения и ГСЧ).

## Команда воспроизведения

Из корня репозитория `rss-shield-highway`:

```bash
python -m experiments.pilot --sconv-probe --out runs/sconv_checkpoint_probe --D 10 --rho 0.6 --steps 5000 --max-steps 5000
```

Кэш стартовых состояний (`start_states`) в режиме `--sconv-probe` создаётся во временном
каталоге и удаляется после завершения; веса модели `.npz` не сохраняются.

## Параметры прогона

- Конфигурация: Proposed (Режим Б), фильтр `MAIN_SERIES` (`observed/nominal/approach/zone=reach`), `D = 10`, `ρ = 0.6 с`, награда `R_v`, сид сети `42`.
- Среда: полный протокольный генератор `ProtocolHighwayEnv` (`warmup = 20.0 с`, `duration = 40 с`, 200 шагов решения на эпизод).
- Бюджет обучения: `5000` шагов решения (`learning_starts = 1000`, `25` эпизодов, сиды `900040–900064`).
- Расписание валидации: `VAL_EVERY = 5000`, `20` фиксированных протокольных сценариев `10000–10019`, `ε = 0`, правило точной отметки (`exact_step = True`).
- Машина и время: Apple M5 Pro, Python 3.14.7, NumPy 2.5.5, `fast_road=enabled`, общее время `68.29 с` (`env 4.32 мс/шаг`, `shield 1.60 мс/шаг`, `policy 0.018 мс/шаг`, `learn 0.43 мс/шаг`).

- Обучение: `5000` шагов, `4001` градиентный шаг, `E = 4977`, перехватов `23` (`TAKEOVER = 9`, `FALLBACK = 14`), столкновений `0`, `N_exec = 4`, `N_exec_other = 0`, проверка всех переходов в буфере (`n = 1: 4956, n = 2: 19, n = 3: 2`): `bad = {start: 0, inner: 0, next: 0}`, `max |R − Σ γ^j r| = 2.2e-16`.
- Контрольная точка (`val_history.csv`):

- Итог `s_conv.json`: `status = "insufficient_checkpoints"` (достигнута 1 из 4 точек окна сходимости), `s_conv = null`, `budget_sufficient = false`, `x_max = 971.044 м`.

## Файлы прогона

- `val_history.csv` — журнал контрольных точек с фактическим и номинальным шагом, номером эпизода, шагом внутри эпизода и числом градиентных обновлений.
- `s_conv.json` — результат `ValidationSchedule.s_conv()`.
- `train_episodes.csv` — по-эпизодная сводка 25 эпизодов обучения.
- `summary.json` — машинный журнал, параметры, итоговые счётчики, проверка буфера и тайминги.
