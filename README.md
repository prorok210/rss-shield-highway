# rss-shield-highway

**Назначение.** RSS-фильтр безопасности для DQN-агента в highway-env: маска действий, задержка
исполнительного тракта τ = Δt, супервизорные команды TAKEOVER / ABORT / FALLBACK. Экспериментальный
протокол исследования — `docs/protocol/`.

**Текущее состояние.** Протокол исследования — `docs/protocol/Протокол_исследования_RSS-фильтр.docx`.
Пакет верификации: 114 тестов, все строки таблицы 3 — pass. Основное обучение DQN ещё не запускалось;
короткий сквозной пилот цепочки обучения — `python -m experiments.pilot --out runs/pilot_run`.
Зафиксированный прогон пилота лежит в `runs/pilot_run/` (`report.md`, `pilot_log.txt`, `summary.json`,
таблицы эпизодов); CI (`pilot.yml`) повторяет его и публикует `report.md` в PR. Пилот проверяет только
работоспособность цепочки; H1–H3 им не проверяются.

Фильтр в экспериментах работает в конфигурации основной серии `MAIN_SERIES` (`rss_shield/shield.py`:
модель соседней полосы observed, номинальный прогноз автомобилей в полосах манёвра, боковое правило
«перекрытие или сближение»). Пакет верификации и таблица 3 строятся на конфигурации `ShieldConfig`
по умолчанию (прогноз в полосах манёвра по границам −8 / +3 м/с²); строки T2b используют её явно.

## Быстрый старт

Требуется Python ≥ 3.10. Статистический план (`analysis/`) использует scipy (в `requirements.txt`).

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
PYTHON=python ./run_all.sh     # код выхода 0 = все строки таблицы 3 pass
```

`run_all.sh` прогоняет pytest, контрольные сценарии, профиль манёвра и собирает `results/` и `logs/`.
Сравнение с эталоном: `diff -r expected/ results/` (могут отличаться только время прогона,
строки ОС/Python и хэши, если менялся код).

## Карта репозитория

| Путь | Что это |
|---|---|
| `rss_shield/` | подкласс `MDPVehicle` (FIFO на 2 кадра, ограничители), фильтр с маской и иерархией, сценарии, интеграция с `HighwayEnv` |
| `tests/` | 114 pytest-тестов; `tests/reference.py` — независимый эталон таблицы 2, `tests/queue_reference.py` — независимый эталон маски для команд в очереди |
| `tools/make_table3.py` | сборка `results/table3.md` и `table3.csv` из журналов и pytest |
| `expected/` | эталонный прогон пакета верификации |
| `runs/verification_run/` | зафиксированный контрольный прогон (`results/`, `logs/`) |
| `runs/pilot_run/` | зафиксированный прогон пилота: `report.md`, `pilot_log.txt`, `summary.json`, таблицы эпизодов (модель `.npz`, кэш стартовых состояний и полные журналы шагов в git не кладутся) |
| `sim/` | точное ускорение highway-env 1.12.1 и побитовый тест эквивалентности `sim/test_fast_road.py` |
| `docs/protocol/` | протокол исследования (`Протокол_исследования_RSS-фильтр.docx`) |
| `experiments/` | основной генератор трафика, 86-признаковое наблюдение, DQN на NumPy, semi-MDP-раннер со счётчиками, единое правило события и старта H1 (`h1.py`), сквозной пилот |
| `analysis/` | исполняемый статистический план (п. 7.9): смешанные модели (`models.py`), семь первичных проверок H2 / H3 как именованные функции, поправка Холма, анализ чувствительности с общими сценариями и правило согласования (`plan.py`), проверки H1 (`binomial.py`), запуск на таблице эпизодов (`python -m analysis.run`), мощность H1a / H1b по числу эпизодов с корректным стартом (`python -m analysis.power`) |
| `configs/` | заготовки: сиды и сетка D × ρ |
| `.github/workflows/verify.yml` | CI: Python 3.13 и 3.14, сверка `table3.csv` с эталоном, тест эквивалентности `sim/` |
| `.github/workflows/pilot.yml` | CI: тесты `experiments/`, замер шага, короткий пилот; отчёт публикуется в PR |

## Правила

- `tests/reference.py` и `expected/` **не меняются**.
- Любое изменение `rss_shield/` — через PR с зелёным CI и обновлённым `expected/`; в описании PR
  указывается причина.
- `sim/` — точное ускорение highway-env для экспериментов; любое его изменение — только
  с зелёным `sim/test_fast_road.py`.
- Прямых коммитов в `main` нет: только через PR.
